# Crosstalk

A daily code-breaking word game. Four hidden code words numbered 1–4; each round you get three clue words and enter the 3-digit code they point to. Crack two codes in as few rounds as you can (8 max).

- **Easy** – true code shown after every round
- **Medium** – only correct positions are marked
- **Hard** – only the number of correct digits is shown

Single static `index.html`, no build step or backend. Stats and progress are saved in the browser (localStorage).

Live at https://nathanpoff.com/izzygame
